# Audit antislop 001: Halaman Teams (2026-10-04)

Mode: **AFTER**. Belum ada yang diperbaiki; pilih nomor yang mau dikerjakan.

**Cakupan:** `/teams` (daftar tim + 5 modal), detail tim, edit tim.
File: `components/sections/TeamsPage/{TeamsLandingSection,TeamDetailSection,TeamEditSection,TeamLogoField,TeamLogo}.tsx`.
Halaman lain (scoring, jadwal, landing publik) tidak diaudit.

**Arah desain:** tidak ada `DESIGN.md`. Acuannya desain dashboard yang sudah ada
(Figma di `Gambaran/`). Komponen baru (field logo, banner hasil, state
loading/error) mengikuti gaya yang sudah ada, jadi tidak ada arah visual baru.

**Cara cek:** build produksi + Playwright di stack terpisah (DB sementara), 37
langkah klik dengan role admin/scorekeeper/viewer. Urutan Tab dan tombol Escape
dicek dengan probe. Warna diambil dari piksel yang benar-benar dirender, lalu
dihitung dengan `contrast-check.py` (rumus WCAG 2.x). Lebar 390/768 px dicek
dengan data tiruan.

**Asal:** *lama* = sudah ada sebelum sesi ini. *baru* = dari perubahan sesi ini.
Prioritas mengikuti tier aturan: Hard Gate = TINGGI, Purpose-Gate = SEDANG, Quality Lock = RENDAH.

## TINGGI (Hard Gate)

### 1. Kartu tim tidak bisa dibuka dengan keyboard
- **Aturan:** R-32 · **Asal:** lama
- **Lokasi:** `TeamsLandingSection.tsx:586`, kartu berupa `<div onClick>`
- **Bukti:** probe 45× Tab: 0 kartu tim yang bisa difokus. Pengguna keyboard tidak bisa membuka detail tim, dan tidak bisa memilih tim di mode Hapus Banyak.
- **Usulan:** ganti kartu jadi `<button type="button">` dengan `focus-visible` ring. Di mode Hapus Banyak tambahkan `aria-pressed`.

### 2. Tombol X "Hapus tim" tidak terlihat saat difokus
- **Aturan:** R-32 · **Asal:** lama
- **Lokasi:** `TeamsLandingSection.tsx:620` (`opacity-0 group-hover:opacity-100`)
- **Bukti:** 35 dari 45 langkah Tab jatuh di tombol X yang opacity-nya 0: fokus "hilang" melewati 33 tombol tak terlihat. Di HP tidak ada hover, jadi tombol ini juga tidak pernah muncul. Hapus satu tim di HP hanya bisa lewat Hapus Banyak.
- **Usulan:** `focus-visible:opacity-100` + ring. Untuk HP: tampilkan tombol di layar sentuh (`pointer-coarse`), atau pindahkan "Hapus tim" ke halaman detail.

### 3. Modal tidak bisa ditutup dengan Escape dan fokus bocor ke belakang
- **Aturan:** R-32, R-26 · **Asal:** lama (berlaku untuk 5 modal)
- **Lokasi:** `TeamsLandingSection.tsx:657` (Tambah Tim), `:793` (Import), `:916` (Hapus Tim), `:963` (Hapus Banyak), `:1010` (Timpa Data)
- **Bukti:** probe: Escape tidak menutup modal Tambah Tim maupun Import. Tidak ada `role="dialog"`/`aria-modal`. Tab dari tombol terakhir modal keluar ke halaman di belakangnya. Fokus tidak kembali ke tombol pembuka.
- **Usulan:** satu komponen `Modal` bersama: `<dialog>` + `showModal()` (Escape dan latar `inert` bawaan browser), judul via `aria-labelledby`, fokus dikembalikan ke tombol pembuka saat ditutup.

### 4. Area pilih file di modal Import tidak bisa dipakai lewat keyboard
- **Aturan:** R-32 · **Asal:** lama
- **Lokasi:** `TeamsLandingSection.tsx:842` (`<div onClick>`)
- **Bukti:** dropzone tidak bisa difokus, dan input file memang disembunyikan dari Tab. Tanpa mouse, file tidak bisa dipilih.
- **Usulan:** jadikan dropzone `<button type="button">` (drag & drop tetap jalan), atau tambahkan tombol "Pilih File" di dalamnya.

### 5. Tombol tutup (ikon X) di 4 modal tidak punya nama
- **Aturan:** R-32 (C-4) · **Asal:** lama
- **Lokasi:** `TeamsLandingSection.tsx:802`, `:921`, `:968`, `:1015`
- **Bukti:** tombol hanya berisi ikon, tanpa `aria-label`/teks. Pembaca layar hanya menyebut "tombol". Modal Tambah Tim sudah diberi `aria-label="Tutup"` di sesi ini.
- **Usulan:** `aria-label="Tutup"` di keempatnya (atau otomatis kalau no. 3 dikerjakan).

### 6. Teks putih di tombol kuning Edit/Save: 2.15:1
- **Aturan:** R-25 · **Asal:** lama
- **Lokasi:** `TeamDetailSection.tsx:254`, `TeamEditSection.tsx:527`
- **Bukti:** `#FFFFFF` di `#F59E0B` = 2.15:1. Gagal untuk teks normal (4.5) maupun teks besar (3.0).
- **Usulan (sudah dihitung):** teks gelap `#2D3748` di kuning yang sama = 5.58:1 (warna tombol tidak berubah), atau putih di `#B45309` = 5.02:1.

### 7. Teks putih di tombol teal utama: 3.17:1
- **Aturan:** R-25 · **Asal:** lama (warna brand). Tombol "Coba Lagi" yang baru ikut memakai gaya ini.
- **Lokasi:** `TeamsLandingSection.tsx:473` (Tambah Tim), `:776` (Simpan Tim), `:572`; `TeamDetailSection.tsx:81, 246`; `TeamEditSection.tsx:170, 184, 509` (Back, Coba Lagi)
- **Bukti:** `#FFFFFF` di `#389F9D` = 3.17:1. Ukuran 14–16px semibold bukan "teks besar", jadi butuh 4.5.
- **Usulan:** pakai warna hover yang sudah ada `#2C7D7B` sebagai warna dasar (4.85:1), hover `#236564` (6.74:1). Ini mengubah warna brand, jadi keputusannya di tim desain.

### 8. Tombol Cancel (merah) dan Tambah Pemain (biru) di bawah 4.5:1
- **Aturan:** R-25 · **Asal:** lama
- **Lokasi:** `TeamEditSection.tsx:519` (Cancel `#EF4444`, 3.76:1), `TeamEditSection.tsx:392` (Tambah Pemain `#1E88E5`, 3.68:1, teks 12px)
- **Usulan:** Cancel `#DC2626` (4.83:1) dan Tambah Pemain `#1565C0` (5.75:1). Keduanya warna hover yang sudah dipakai; hover bisa dibuat lebih gelap lagi.

### 9. Abu-abu `gray-400` untuk teks, placeholder, dan ikon: 2.60:1
- **Aturan:** R-25 · **Asal:** lama (teks petunjuk di `:749` diubah isinya di sesi ini, warnanya belum)
- **Lokasi:** `TeamsLandingSection.tsx:749` ("Nama dan nomor punggung…", 11px), `:863` ("Mendukung berkas…"), `:551` (placeholder pencarian), `:547` (ikon kaca pembesar), `:620`, `:663`, `:802`, `:921`, `:968`, `:1015` (ikon X)
- **Bukti:** `#99A1AF` di putih = 2.60:1. Untuk teks butuh 4.5, untuk ikon tombol butuh 3.0.
- **Usulan:** teks petunjuk → `gray-600` (7.56:1), placeholder → `gray-500` (4.84:1), ikon X → `gray-600`.

### 10. Subjudul "Total N Tim Terdaftar…" di latar abu halaman: 3.87:1
- **Aturan:** R-25 · **Asal:** lama
- **Lokasi:** `TeamsLandingSection.tsx:427`
- **Bukti:** `#6A7282` di `#E1E7EA` = 3.87:1 (14px).
- **Usulan:** `gray-600` → 6.05:1.

### 11. Teks 11px di bar Hapus Banyak: 4.39:1
- **Aturan:** R-25 · **Asal:** lama
- **Lokasi:** `TeamsLandingSection.tsx:513`
- **Bukti:** `#E7000B` di `#FEF3F3` = 4.39:1 (selisih tipis dari 4.5).
- **Usulan:** `red-700` → 5.91:1.

### 12. Nama tim terpotong jadi 3–4 huruf di HP
- **Aturan:** R-03 · **Asal:** lama (lebih terasa sekarang karena nama tim asli lebih panjang dari "HMD 1")
- **Lokasi:** `TeamsLandingSection.tsx:580` (`grid-cols-3`), `:627` (logo `w-24`), `:630` (`truncate`)
- **Bukti:** di 390px kartu hanya 93px, padahal kotak logo 96px (melebihi kartu di 9/9 tim). Nama tampil "Bali …", "Kesa…", "Pelit…", bahkan "HMD 10" terpotong. Di 768px pun 6 dari 9 nama masih terpotong. Tidak ada scroll horizontal.
- **Usulan:** di bawah 640px pakai 2 kolom dan logo `w-20`. Nama boleh 2 baris (`line-clamp-2`) daripada dipotong 1 baris, dan nama lengkap ditaruh di `title`.

### 13. Target sentuh di bawah 44px
- **Aturan:** R-03 · **Asal:** lama + baru
- **Lokasi:** X hapus tim 24px (`TeamsLandingSection.tsx:620`), ikon hapus pemain ±24px (`TeamEditSection.tsx:449`), X tutup modal ±28px, X banner ±24px (`TeamsLandingSection.tsx:496`, baru), tombol "Pilih Gambar/Ganti Logo" & "Hapus Logo" ±36px (`TeamLogoField.tsx:71, 83`, baru)
- **Usulan:** area klik minimal 44×44 (padding atau `min-h-11 min-w-11`). Ukuran ikonnya tidak perlu berubah.

### 14. Tabel pemain tanpa empty state
- **Aturan:** R-27 · **Asal:** lama (detail) + baru (edit)
- **Lokasi:** `TeamDetailSection.tsx:155, 202`; `TeamEditSection.tsx:411, 479`
- **Bukti:** tim tanpa pemain (mis. hasil import yang baris pemainnya kosong) hanya menampilkan header tabel kosong tanpa penjelasan.
- **Usulan:** satu baris `colSpan` "Belum ada pemain. Tambahkan lewat Edit Tim." (di halaman edit: "…klik Tambah Pemain").

## RENDAH (Quality Lock)

### 15. Class animasi yang tidak pernah jalan
- **Aturan:** C-1 · **Asal:** lama
- **Lokasi:** `animate-in fade-in zoom-in-95` di kelima modal (`TeamsLandingSection.tsx:657, 793, 916, 963, 1010`)
- **Bukti:** class ini butuh plugin `tw-animate-css` yang tidak terpasang, dan tidak didefinisikan di `globals.css`. Modal muncul tanpa animasi.
- **Usulan:** hapus class-nya, atau tambahkan satu animasi masuk di `globals.css` kalau memang diinginkan.

### 16. Palet warna aksi melebar ke 6 warna
- **Aturan:** R-29 · **Asal:** lama (dari desain Figma)
- **Bukti:** teal (utama), kuning (Edit/Save), merah (Cancel/hapus), biru (Tambah Pemain + bingkai mode edit), hijau (ikon import/sukses), krem (header tabel). Tanpa design system tertulis, tiap tombol "penting" dapat warna sendiri.
- **Usulan:** keputusan tim desain. Saran: teal untuk aksi utama, merah hanya untuk aksi merusak, sisanya tombol netral. Kalau no. 6–8 dikerjakan, sekalian rapikan di sini.

### 17. Bahasa campur Inggris–Indonesia
- **Aturan:** C-1 · **Asal:** lama (judul dari Figma). Teks baru di sesi ini berbahasa Indonesia.
- **Bukti:** "Teams", "Team Statistic", "Player Total Statistic", "NAME/GAME/POINT", "Value", "Back/Edit/Cancel/Save" berdampingan dengan "Tambah Tim", "Simpan Tim", "Batal", "Hapus Logo".
- **Usulan:** pilih satu bahasa untuk dashboard panitia. Singkatan statistik basket (PPG, FG%) tetap boleh.
